# DOCX Viewer for VSCode

Preview Microsoft Word (.docx) documents directly in VSCode with a clean, paper-like view.

## Features

- Opens .docx files in a custom preview editor
- Renders headings, paragraphs, bold/italic/underline text
- Renders tables, ordered/unordered lists, images, and hyperlinks
- Clean paper-like preview with proper typography
- Automatically reloads when the file changes on disk

## Usage

1. Open any `.docx` file in VSCode
2. The file will automatically open in the DOCX Preview editor
3. Alternatively, use the Command Palette and run "DOCX Viewer: Preview DOCX File"

## Requirements

- VSCode 1.75.0 or higher

## Known Limitations

- This is a read-only preview; editing is not supported
- Complex Word features (headers/footers, text boxes, tracked changes, etc.) may not render perfectly
